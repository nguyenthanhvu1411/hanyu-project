# HanYu Admin Web

Bộ khung Next.js Admin cho hệ thống học tiếng Trung.

- Routing hiển thị bằng tiếng Việt không dấu.
- `src/app/(xac-thuc)` dành cho xác thực.
- `src/app/(quan-tri)` dành cho khu vực quản trị.
- Design assets nằm trong `public/`.
- Đây là gói cấu trúc nền tảng; các module sẽ được triển khai logic ở các bước tiếp theo.
